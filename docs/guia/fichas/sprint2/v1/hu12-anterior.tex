\def\HUDescripcion{%
Un estudiante al que se le niega el ingreso pregunta por qué. Si el sistema solo dice «no
habilitado», el personal de control no tiene respuesta y el estudiante vuelve a la
oficina: esta historia evita ese viaje.

El motivo es obligatorio al inhabilitar. Sin él, el sistema no registra la condición y lo
dice con todas las letras, tanto en la pantalla como en la API. Al habilitar, en cambio,
el motivo no corresponde: si el estudiante estaba inhabilitado y se lo habilita, el motivo
anterior se borra, para que no quede una explicación que ya no aplica.

Junto con el motivo queda constancia de quién lo registró y cuándo, que es lo que permite
resolver una discusión en la puerta sin buscar a nadie. El personal de control verá el
motivo al verificar al estudiante en la puerta (HU-19), sin entrar a esta pantalla.

El motivo viaja en la misma tabla que la condición: son el mismo hecho, y separarlos
obligaría a unir dos tablas para responder la pregunta más frecuente del sistema.}

\def\HUCriterios{%
\item Dado que se inhabilita a un estudiante, Cuando no se indica el motivo, Entonces el
      sistema rechaza la operación y lo señala.
\item Dado que se inhabilita a un estudiante con su motivo, Cuando se guarda, Entonces el
      sistema registra la condición junto con el motivo.
\item Dado que un estudiante está inhabilitado, Cuando se consulta el listado del examen,
      Entonces el motivo se muestra junto a su condición.
\item Dado que un estudiante inhabilitado pasa a estar habilitado, Cuando se registra la
      nueva condición, Entonces el motivo anterior deja de figurar.
\item Dado que se registra una inhabilitación, Cuando se la consulta, Entonces consta
      quién la registró y cuándo.
\item Dado que se inhabilita a varios estudiantes a la vez, Cuando se aplica el motivo,
      Entonces el sistema lo registra para todos ellos.
\item Dado que se inhabilita a un estudiante, Cuando la operación se completa, Entonces
      queda asentada en la bitácora con su autor.
\item Dado que el docente accede desde un dispositivo móvil, Cuando registra un motivo,
      Entonces la interfaz se adapta de forma completamente responsiva.}
