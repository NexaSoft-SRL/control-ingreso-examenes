\def\HUDescripcion{%
El tablero (HU-27) dice cuántos faltan; esta pantalla dice quiénes. Es la lista nominal de
los habilitados del examen, y a cada uno le pone una de tres situaciones: ingresado, no
presentado o expulsado. La distinción importa: un expulsado estuvo en el aula y un no
presentado nunca llegó, y confundirlos falsea el acta.

Cada fila trae la hora que corresponde ---la del ingreso o la de la expulsión--- y, en el
caso del expulsado, el motivo. Un ingreso anulado (HU-21) devuelve al estudiante a la
situación de no presentado: la anulación existe justamente para deshacer un registro
equivocado.

La lista se filtra por examen y por ambiente, que es como se la usa: el responsable mira
un aula a la vez.

La consulta es de solo lectura, y eso no depende de que la pantalla no muestre botones: el
módulo de monitoreo declara únicamente rutas \texttt{GET}. Cualquier intento de escribir
sobre ellas se rechaza.}

\def\HUCriterios{%
\item Dado un examen en curso, Cuando se consulta la lista, Entonces cada habilitado
      figura como ingresado, no presentado o expulsado.
\item Dado que un estudiante fue expulsado, Cuando se lo ve en la lista, Entonces consta
      el motivo y la hora de la expulsión.
\item Dado que el examen se rinde en varios ambientes, Cuando se filtra por uno, Entonces
      se ven solo los estudiantes de ese ambiente.
\item Dado que un ingreso fue anulado, Cuando se consulta la lista, Entonces el estudiante
      vuelve a figurar como no presentado.
\item Dado que se consulta la lista, Cuando se la lee, Entonces el resumen cuenta
      ingresados, no presentados y expulsados.
\item Dado que la consulta es de solo lectura, Cuando se intenta escribir sobre sus
      rutas, Entonces el sistema no lo permite.
\item Dado que un rol no tiene el permiso de monitoreo, Cuando abre la lista, Entonces el
      sistema responde con una negativa explícita.}
